# Peachy selected brand kit v3

This kit uses the selected flowing-channel peach as the primary identity. The generated reference was redrawn rather than auto-traced, preserving its broad S gesture while removing gradients, rough edges, color drift, and stray pixels.

## Construction

- The outer fruit is one custom asymmetrical Bézier contour in `#FF9270`.
- The S-shaped center channel is a true transparent cutout, not a lighter overlay.
- The short stem uses `#F57B57` and visually continues the channel into the leaf.
- The leaf uses `#7DB37C` and is enlarged slightly for small-size clarity.
- The app icon and Android background use `#FFF1EC`.
- No gradients, shadows, highlights, or outlines are used.

## Included

- Opaque 1024 px app icon
- Transparent master mark
- Android adaptive foreground, background, and white monochrome layers
- Transparent splash mark and 200 px presentation preview
- Horizontal and stacked wordmarks
- Updated favicon
- Updated pattern, empty state, and seven-peach celebration
- Original 14 outline and 14 active-state UI icons
- Organic blob SVG assets

The wordmark SVG specifies M PLUS Rounded 1c ExtraBold. The PNG preview uses Arial Rounded Bold as the locally available preview substitute.
